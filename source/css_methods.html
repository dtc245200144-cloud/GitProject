Thực Hành Nhúng CSS Vào Trang Web

Phần 1: Inline Style

Đoạn văn này được thay đổi màu sắc bằng thuộc tính inline-style viết trực tiếp trên thẻ HTML.

Phần 2: Internal Style

Đoạn văn này được thay đổi màu sắc bằng thẻ <style> nằm trong phần <head> của trang web.

Phần 3: External Style

Đoạn văn này được thay đổi màu sắc bằng file CSS riêng biệt css_methods.css thông qua thẻ <link>.
